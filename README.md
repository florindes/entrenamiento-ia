# Entrenamiento IA V2

Versión móvil/PWA de tu rutina con:
- Rutina A/B/C.
- Registro kg / reps / RIR.
- Temporizadores configurables.
- Historial, volumen, PR y peso corporal.
- Gráfica por ejercicio.
- Copia de seguridad JSON.
- Analizador local.
- Backend seguro `/api/coach` para IA real con OpenAI.
- Endpoint `/api/health` para comprobar si la IA está configurada.
- Instalación como PWA desde una URL HTTPS.

Lee `DEPLOY_CELULAR.md` para publicarla e instalarla.
